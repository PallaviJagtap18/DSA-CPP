# Introduction to Algorithms

An algorithm is a finite set of step-by-step instructions used to solve a problem or perform a specific task.

In simple words, an algorithm tells us what to do, how to do it, and in what order to get the required output.

Example: Algorithm to Add Two Numbers
Step 1: Start
Step 2: Take two numbers A and B
Step 3: Calculate Sum = A + B
Step 4: Display Sum
Step 5: Stop

Here, the above steps form an algorithm for adding two numbers.

---

## Characteristics of an Algorithm

A good algorithm has the following characteristics:

1. Input

An algorithm should accept zero or more inputs.

Example: Two numbers A and B.

2. Output

An algorithm should produce at least one output.

Example: The sum of two numbers.

3. Definiteness

Every step of the algorithm should be clear and unambiguous.

The user should understand exactly what needs to be done.

4. Finiteness

An algorithm must finish after a finite number of steps.

It should not continue forever.

5. Effectiveness

Every step should be simple, practical, and executable within a reasonable amount of time.

6. Correctness

The algorithm should produce the correct result for valid inputs.

7. Efficiency

An algorithm should use less time and memory as much as possible.

## Algorithm Design Tools

Algorithm design tools are used to represent the logic of an algorithm before writing actual code.

The two common design tools are:

- Pseudocode
- Flowchart

---

## 1. Pseudocode

Pseudocode is a simple, informal way of writing the steps of an algorithm using English-like statements.

It is not written according to the syntax of any particular programming language.

Example: Find the Larger Number

START
Input A and B
IF A > B
    Display A
ELSE
    Display B
END IF
STOP

## Advantages of Pseudocode
- Easy to understand
- Easy to write
- Language independent
- Helps convert logic into actual code
- Makes errors in logic easier to find

---

## 2. Flowchart

A flowchart is a graphical representation of an algorithm. It uses standard symbols to show the steps and flow of a solution.

- Common Flowchart Symbols

Symbol	                    Name	                     Purpose
Oval	                    Start/Stop	                 Represents beginning or ending
Rectangle	                Process	                     Represents calculation or operation
Parallelogram	            Input/Output	             Represents input or output
Diamond	                    Decision	                 Represents a condition
Arrow	                    Flow Line	                 Shows the direction of execution

## Advantages of Flowchart

- Easy to understand
- Easy to understand 
- Easy to communicate 
- Helps in planning 
- Finds errors easily 
- Makes coding easier 
- Easy to analyze 
- Useful for documentation
